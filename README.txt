GGTR Audio Website — Upload Package

Contents
- index.html: responsive bilingual (English/Turkish) GGTR Audio website
- assets/ggtr-audio-logo.png: GGTR Audio logo
- assets/ggtr-tone-match-ui.png: GGTR Tone Match interface screenshot

Publish with GitHub + Cloudflare Pages
1. Open the GitHub repository: https://github.com/ggtraudio-afk/ggtraudio-website
2. Upload index.html and the complete assets folder to the main branch (keep the folder structure).
3. Commit the changes to main.
4. Cloudflare Pages should deploy automatically from the connected repository.

Cloudflare Pages build settings
- Framework preset: None
- Build command: leave blank
- Build output directory: / (root)

The GGTR Tone Match introduction video is embedded directly in the page using YouTube's privacy-enhanced embed domain.
