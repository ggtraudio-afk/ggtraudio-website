GGTR AUDIO WEBSITE — READY TO UPLOAD

Files:
- index.html
- assets/ggtr-audio-logo.png
- assets/ggtr-tone-match-ui.png

Publish / update with GitHub + Cloudflare Pages:
1. Open https://github.com/ggtraudio-afk/ggtraudio-website
2. Open the repository and choose Add file > Upload files.
3. Extract this ZIP on your computer.
4. Upload index.html and the assets folder (keep the folder structure).
   If GitHub does not accept the folder as a folder, open assets locally,
   select both PNG files, and upload them while the repository's assets
   folder is open. Do not upload the images beside index.html.
5. Commit directly to the main branch.
6. Cloudflare Pages is connected to main and should deploy automatically.
7. Open https://ggtraudio.pages.dev/ and hard-refresh (Ctrl + F5).

The website uses the existing GGTR Audio logo and the real GGTR Tone Match
interface screenshot from the assets folder. The page is bilingual (EN/TR),
responsive, and its download buttons point to the latest GitHub Release.
