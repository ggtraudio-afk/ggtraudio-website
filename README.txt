GGTR Audio Website — upload package

Contents
- index.html: bilingual (English/Turkish) responsive website
- assets/ggtr-audio-logo.png: supplied GGTR Audio logo
- assets/ggtr-tone-match-ui.png: supplied GGTR Tone Match interface screenshot

Publish with GitHub + Cloudflare Pages
1. Open the GitHub repository: https://github.com/ggtraudio-afk/ggtraudio-website
2. Choose Add file > Upload files.
3. Extract this ZIP on your computer first.
4. Upload index.html and the assets folder (keep the folder structure).
5. Commit the changes to the main branch.
6. Cloudflare Pages should deploy automatically.

Cloudflare Pages build settings
- Framework preset: None
- Build command: leave blank
- Build output directory: / (root)

The download buttons point to the latest GGTR Tone Match GitHub Release:
https://github.com/ggtraudio-afk/ggtraudio-tone-match/releases/latest

The site is bilingual (EN/TR); the language selector is in the top navigation.
